# ユーザーガイド

このガイドでは、Probance候補者スペースの使い方を説明します：セッションの開始、問題への回答、結果の確認、認定の管理。

## ダッシュボード

ダッシュボードはスタート画面です。ここには以下が表示されます：

- 利用可能な認定パック
- 各認定のステータス（有効、まもなく期限切れ、期限切れ、未取得）
- 最近のセッション履歴
- 新しいセッションを開始するボタン

このページでパックを選び、モードを選び、開始します。

## 2つのセッションモード

### 試験モード

公式モードです。すべての問題に即時フィードバックなしで回答します。スコアは最後に計算され、認定を取得できるかどうかが決まります。

### トレーニングモード

練習モードです。問題ごとに回答を確認し、正誤をすぐに確認できます。このモードは認定には反映されません。

## セッションの開始

1. ダッシュボードでパックを選ぶ
2. モード（試験またはトレーニング）を選ぶ
3. 開始ボタンをクリック

次の場合、試験セッションが拒否されることがあります：

- そのパックの有効な認定がすでにある
- 最近の不合格後の待機期間が有効

該当する場合は説明メッセージが表示されます。

## セッション中

- 問題は1問ずつ表示されます
- タイマーが残り時間を示します
- 正解が1つだけの問題もあれば複数ある問題もあります — 問題文をよく読んでください

試験モードでは最後まで即時フィードバックなしで進みます。トレーニングモードでは問題ごとに回答を確認してから次へ進めます。

最後の問題を送信したとき、終了ボタンをクリックしたとき、または時間が切れたときにセッションが終了します。

試験モードでは**放棄**ボタンが利用できます。このボタンを使用すると、スコアは計算されずセッションは**放棄**としてマークされます — 何問正解していても認定には反映されません。

## 結果の確認

結果ページには以下が表示されます：

- 取得したスコアと合格基準
- ステータス：合格、不合格、期限切れ、または放棄
- 対象パックと受験日

トレーニングモードでは、すべての問題を自分の回答と正解のハイライト付きで確認できます。

試験を受けた場合：

- 合格するとパックに設定された期間の認定が有効になります
- 不合格後は再受験まで待機期間が設けられることがあります
- 時間切れの場合は回答済みの問題でスコアが計算されます — スコアに応じて合格または不合格になります
- 放棄（放棄ボタン）の場合はスコアが計算されず、認定には一切反映されません

## 履歴と認定

ダッシュボードから各認定のステータスを確認できます：

- **有効** — 認定済み、有効期限が表示されます
- **まもなく期限切れ** — 認定の有効期限まで30日未満
- **期限切れ** — 試験の再受験が必要
- **未取得** — このパックをまだ合格していません

履歴には過去のセッションがスコアと結果とともに一覧表示されます。

## 困ったとき

- 認定が有効な間は試験を開始できません → 期限切れを待つか管理者に連絡してください
- 不合格後に試験を開始できません → 待機期間中です。いつ再受験できるかをメッセージで確認してください
- ページが読み込まれません → 再読み込みしてください。問題が続く場合は管理者に連絡してください
- パックへのアクセスがなくなった → 管理者に連絡してください

## よくある質問

### 認定を開始できないのはなぜですか？

2つの理由が考えられます：そのパックの有効な認定がすでにあるか、不合格後の待機期間が有効になっています。ダッシュボードのメッセージでどちらが該当するか確認できます。

### 部分的に正しい回答を選んだ場合、スコアは正しいですか？

はい。問題は、すべての正解を選び、かつ不正解を1つも選ばなかった場合にのみ1点になります。正解を1つ余分に選んだり、正解を1つ見逃したりすると、大部分が正しくても0点になります。

### トレーニングと試験の違いは何ですか？

トレーニングは問題ごとに即時フィードバックがある練習用です。試験は受験中にフィードバックがない公式の評価で、その結果が認定に反映されます。

### 時間が切れるとどうなりますか？

セッションは自動的に終了し、回答済みの問題に基づいてスコアが計算されます — パックの合格基準に対するスコアによって合格または不合格になります。

### 放棄するとどうなりますか？

放棄ボタンをクリックすると、セッションは即座に終了しスコアは計算されません。ステータスは**放棄**と表示され、何問正解していても認定には反映されません。

### 後でセッションを再開できますか？

いいえ。セッションは一度で完了する必要があります。ページを閉じた場合、セッションはタイマーが切れるまでアクティブのままで、その後回答済みの問題でスコアが計算されます。放棄ボタンをクリックした場合は、スコアなしで即座に終了します。
