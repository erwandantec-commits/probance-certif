# 管理者ガイド

このガイドでは、コードには踏み込まず、主な管理画面の動作を説明します。

## 管理エリアの役割

管理エリアでは以下を行います。

- 受験者が実施したセッションを追跡する
- 受験者の詳細を確認する
- 認定を管理する
- パックを管理する
- 問題を管理する
- 問題のパフォーマンスを分析する
- ユーザーを管理する

## セッション

`セッション`ページでは、最近の受験状況を監視できます。

確認できる内容:

- 受験者
- パック
- セッション種別
- スコア
- ステータス
- 詳細へのリンク

セッション詳細では、次の操作ができます。

- 出題された問題を確認する
- 受験者の回答を確認する
- 正解を確認する
- 問題の詳細画面をすばやく開く
- 問題のパフォーマンス分析を開く

## 受験者

受験者の詳細画面では、1人の受験者に関する情報をまとめて確認できます。

確認できる内容:

- 受験者情報
- セッション履歴
- 認定
- 学習経路に関連する一部の管理設定

## 認定

`認定`ページでは、受験者別およびパック別の追跡ビューを表示します。

通常、次の内容が表示されます。

- 認定ステータス
- 最終取得日
- 有効期限
- 最終セッション詳細へのリンク

## ユーザー

`ユーザー`ページでは、アプリケーションのアカウントを管理します。

実行できる操作:

- アカウント一覧を確認する
- 一部のユーザー情報を編集する
- 必要に応じてロールを調整する

## パック

`パック`ページでは、ツールで利用できる認定を管理します。

パックでは次の項目を定義できます。

- 名前
- 表示色
- 所要時間
- 合格基準
- 問題数
- 選択ロジック
- 認定の有効期間
- 不合格後のクールダウン

`パックを編集`から、次の操作ができます。

- パック設定を調整する
- 関連する問題を確認する
- 問題編集を開く
- 問題のパフォーマンスビューを開く

## 問題

`問題`ページは、全体の問題バンクです。

実行できる操作:

- 問題を検索する
- フィルタリングする
- 編集する
- 削除する
- 問題のパフォーマンスを開く

## 問題のインポート

インポートページでは、問題を一括で追加または更新できます。

3つのモードがあります。

- `リセット`: IDに基づいて新しい問題を作成し、既存の問題/回答を置き換えます。ファイル内に存在する行だけが処理されます。ファイルに含まれていない問題は削除されません。既存の翻訳は要確認としてマークされ、回答が再作成されると回答の翻訳は削除されます。
- `更新`: IDに基づいて参照元の問題/回答のみを作成または更新します。このモードでは翻訳列を読み込みません。
- `翻訳`: すでにソースに存在する問題について、選択した言語の翻訳テキストのみを更新します。このモードでは、ソース、正解、カテゴリ、レベルは変更されません。

リセットモードまたは更新モードで既存の問題が変更された場合、その回答はいったん削除され、その後再作成されます。

ソース言語はプログラムで定義されます。`リセット`および`更新`モードでは、インポート時にこの言語が強制され、ファイルに期待される言語が表示されます。`翻訳`モードでは、言語リストからプログラムのソース言語が除外されます。

### FAQ

#### 同じIDで問題を再インポートした場合、翻訳はどうなりますか。

同じプログラム内で同じ外部IDを持つ問題を再インポートすると、インポート処理は同じ内部問題を見つけます。そのため、設問文の翻訳は問題に紐づいたままですが、ソースが変更されたため要確認としてマークされます。

一方、回答はリセットまたは更新の際に削除され、その後再作成されます。そのため、回答の翻訳は削除され、`翻訳`モードで再インポートする必要があります。

## 分析

`分析`ページでは、完了または期限切れになったすべてのセッションを対象に、問題別の集計ビューを表示します。

### 全体統計

ページ上部のサマリーバーには、現在のフィルターに対応する主要な指標が表示されます。

- **問題数** — 少なくとも1回回答された異なる問題の数
- **回答数** — 記録された回答の総数
- **正解率** — 正解回答の全体的な割合
- **誤答率** — 誤答回答の全体的な割合
- **未変更** — セッション時と同じテキストを持つ問題
- **変更済み** — 一部のセッション後にテキストが更新された問題
- **削除済み** — バンクから削除されたが履歴に残っている問題

### スコープフィルター

| フィルター | 用途 |
|-----------|------|
| 問題ID | 外部識別子で特定の問題を検索 |
| セッション種別 | 試験・トレーニング・両方に絞り込み |
| パック | 特定のパックに絞り込み |
| 問題の状態 | 未変更・変更済み・削除済みでフィルター |
| カテゴリ | `knowledge_required` の値でフィルター |
| 開始日 / 終了日 | セッション開始日の期間を指定 |

### メトリクスの高度なフィルター

各メトリクスに対して比較演算子で絞り込みができます。

- `=` 完全一致
- `>=` 以上
- `<=` 以下
- `範囲` — 2つの値で区間を指定

利用可能なメトリクス：正解率（%）、誤答率（%）、回答数。

例：誤答率が60%以上かつ回答数が10件以上の問題のみ表示。

### 問題テーブル

テーブルは選択した列（ヘッダーをクリック）で並び替え可能で、1ページあたり20行で表示されます。

| 列 | 説明 |
|----|------|
| 順位 | すべての問題を対象にした正解率の降順ランキング |
| ID | 問題の外部識別子 |
| 問題 | 110文字に切り詰めたテキスト |
| カテゴリ | `knowledge_required` の値 |
| 状態 | ラベル：未変更 / 変更済み / 削除済み |
| 回答数 | 問題が提出された回数 |
| 正解率 | 正解した割合 |
| 誤答率 | 誤答した割合 |
| アクション | 問題エディターを開く · セッションの詳細を表示 |

### スナップショットの仕組み

セッションは、受験時点での問題テキストのスナップショットを記録します。これにより：

- **変更済み**の問題は統計が保持されます — 数値は有効ですが、表示されるテキストは現在のものです
- **削除済み**の問題は、記録された回答が1件以上ある限り、分析上で表示され続けます

### ズーム：問題別のセッション詳細

ズームボタンを押すと、その問題が含まれていたすべてのセッションが一覧表示されます。

- セッションの日時
- 受験者（メール）
- パックとセッション種別
- 結果：OK（正解）または KO（不正解）
- セッション詳細へのリンク

メインページのセッション種別フィルターと日付範囲は自動的に引き継がれます。

### 代表的な活用例

- **難しい問題** — `誤答率`の降順で並び替え、問題のある設問を特定して文言や選択肢を見直す
- **利用頻度の低い問題** — `回答数`の昇順で並び替え、ほとんど出題されていない問題を把握する
- **古い問題バンク** — `変更済み`や`削除済み`でフィルターして、ソースと一致しない問題を管理する
- **期間の影響分析** — 日付とパックのフィルターを組み合わせてコホートを比較し、更新の影響を評価する
